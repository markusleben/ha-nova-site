HA NOVA — Try HA NOVA on a demo house

Talk to a test Home Assistant house with no real devices. Pick your AI app, then ask it to turn off a light.

Before you use the demo

Public demo: everyone shares one account. Other visitors can see what you enter until the next reset. Never enter real names, addresses, passwords, API keys, or tokens. Don’t connect real accounts or devices.

Which app do you use?

Claude

No install. A free Claude account works. Add it on the web or in the Claude desktop app; then it works in the Claude phone app too.

Add to Claude

  1. Add it. Choose Add to Claude. Claude opens with the demo filled in. If it asks how to sign in, choose “Sign in now” and “Use Claude’s published identity”. Then choose Add.
  2. Log in. The demo house’s login opens (if not, choose Connect). It asks to let Claude in: that is the demo, not your home. Type demo and demo.
  3. Ask. Open a new chat with no files and no other connectors on. Say one of the lines below.
Good to know in Claude

A free Claude plan can add one connector of its own. Already used it? Remove that one first in Claude: Settings → Connectors.

Unlocking a door asks you first. Here, Claude shows a short code, and you type it back. Claude sees the code too, so it is a light check. At home, a linked phone asks instead.

Your connection stays. Only the house resets every hour. That takes a few minutes.

Claude asks before each step at first. To ask less, open Settings → Connectors → HA NOVA demo. Set the read-only tools and “Control a device” to “Always allow”. Leave “Run a confirmed change” on “Needs approval”: the demo has no phone, so that question is the check before the door unlocks.

Done? Remove the demo in Claude: Settings → Connectors. That frees the slot for your own home.

ChatGPT

In ChatGPT (Plus or Pro), on the web: paste this address. It worked with ChatGPT Pro in our test; your plan’s rules apply. The free plan can’t add its own connectors.

https://demo.hanova.app/api/ha_nova/mcp
  1. Add it. Open chatgpt.com/plugins, choose +, then “Add custom MCP server”. Name it HA NOVA demo and paste the address under “Connection”. Pick OAuth, tick “I understand and want to continue”, then choose Create.
  2. Log in. The demo house’s login opens. Type demo and demo. ChatGPT often fails the first sign-in. Just choose Connect again. Still stuck on Connect? Remove the plugin in ChatGPT and add it again.
  3. Ask. Open a new chat with no files and no other connectors on. Type @HA NOVA demo and one of the lines below.

An app on my computer

For Codex, Claude Code, OpenCode, or Antigravity. Install HA NOVA, then connect the demo house.

1. Install HA NOVA. On a Mac or Linux, paste this in the Terminal:

$
curl -fsSL https://raw.githubusercontent.com/markusleben/ha-nova/main/install.sh | bash

On Windows, paste this in PowerShell:

PS>
irm https://raw.githubusercontent.com/markusleben/ha-nova/main/install.ps1 | iex

2. Connect the demo. A setup page opens. If it shows “Try HA NOVA on a demo house”, choose it. If not, open a new terminal and run this:

$
ha-nova try

3. Ask. Start your AI app in a new, empty folder, in a new chat. Don’t let it run commands or open files without asking you. Say one of the lines below. Done? ha-nova try --stop removes the demo house.

Then say these, one at a time

  1. “In the demo house, turn off the kitchen lights.”
  2. “In the demo house, unlock the entrance door.” It asks you first.
  3. “In the demo house, where is the bed light used?”

Open the house next to the chat and watch it change. Log in with demo / demo.

How the demo works

One shared house, one shared login, a fresh start every hour.

  • Everything resets at the top of every hour (UTC). Next reset in .

  • Other visitors can write text in the house, and your AI app reads it. Use the demo in a new chat (on a computer: in an empty folder), with no files and no other connectors on.

  • In the house, everyone is an admin with demo / demo. Change anything, break things: it comes back at the next reset.
