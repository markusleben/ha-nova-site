HA NOVA — Try HA NOVA on a demo house

A Home Assistant with no real devices. Pick your AI app, then ask it to turn off a light.

Before you use the demo

Everyone shares this demo: others can see what you enter, so never use real names, addresses, passwords, keys, or accounts.

Which app do you use?

Claude

Add to Claude (opens in a new tab)

No install, and a free Claude account works. Add HA NOVA on the web or in the desktop app, then use it on your phone too.

  1. Add it. Choose Add to Claude. Claude opens with the demo filled in. If it asks how to sign in, choose “Sign in now” and “Use Claude’s published identity”. Then choose Add.
  2. Log in. The demo house’s login opens (if not, choose Connect). It asks to let Claude in: that is the demo, not your home. Type demo and demo.
  3. Ask. Start a new chat with no files, and with nothing else added. Say one of the lines below.
Good to know: no form, Team plans, and more

On the free plan, Claude lets you add only one of these. Already added a different one? Remove it first: Customize → Connectors.

On a Team or Enterprise plan? An owner adds it once for everyone: Add for my organization (opens in a new tab)

No form? Click + → Add custom connector, and paste this address:

https://demo.hanova.app/api/ha_nova/mcp

Unlocking a door asks you first. Here, Claude shows a short code, and you type it back. Claude sees the code too, so it is a light check. At home, a linked phone asks instead.

Your connection stays. Only the house resets every hour. That takes a few minutes.

Claude asks before each step at first. To ask less, open Customize → Connectors → HA NOVA demo. Set the read-only tools and “Control a device” to “Always allow”. Leave “Run a confirmed change” on “Needs approval”. The demo has no phone, so that question is the check before the door unlocks.

Done? Remove the demo in Claude: Customize → Connectors. That frees the free plan’s one spot for your own home.

ChatGPT

ChatGPT: use it on a computer, with a paid plan. On a phone, ChatGPT can only answer. Copy this address:

https://demo.hanova.app/api/ha_nova/mcp
  1. Add it. Open chatgpt.com/plugins (opens in a new tab) and choose +, then “Add custom MCP server”. Name it HA NOVA demo and paste the address under “Connection”. Pick “OAuth”, tick “I understand and want to continue”, then choose “Create as a plugin”.
  2. Log in. The demo house’s login opens. Type demo and demo. ChatGPT often fails the first login. Just choose Connect again.
  3. Ask. Start a new chat with no files, and with nothing else added. Type @HA NOVA demo and one of the lines below.

Menus look different? See the exact names in the chat apps guide (opens in a new tab).

Good to know in ChatGPT

We tested it with Pro, and your plan’s rules apply. The free plan can’t add HA NOVA.

Still stuck on Connect? Remove HA NOVA demo in ChatGPT and add it again.

An app on my computer

For Claude Code, Claude Desktop, Codex CLI, OpenCode, Google Antigravity, or Hermes Agent (preview).

1. Install HA NOVA. On a Mac or Linux, paste this in the Terminal:

$
curl -fsSL https://raw.githubusercontent.com/markusleben/ha-nova/main/install.sh | bash
Read the install script (opens in a new tab)

On Windows, paste this in PowerShell:

PS>
irm https://raw.githubusercontent.com/markusleben/ha-nova/main/install.ps1 | iex
Read the install script (opens in a new tab)

2. Connect the demo. A setup page opens. If it shows “Try HA NOVA on a demo house”, choose it. If not, open a new terminal and run this:

$
ha-nova try

3. Ask. Start your AI app in a new, empty folder, in a new chat. Say one of the lines below. Keep your app asking before it runs commands or opens files.

Good to know on your computer

Done? ha-nova try --stop removes the demo house.

Then say these, one at a time

  1. “In the demo house, turn off the kitchen lights.”
  2. “In the demo house, unlock the entrance door.” It asks you first.
  3. “In the demo house, where is the bed light used?”

Open the house next to the chat and watch it change (opens in a new tab). Log in with demo / demo.

How the demo works

One shared house, one shared login, a fresh start every hour.

  • Everything resets at the top of every hour (UTC). Next reset in .

  • Other visitors can write text in the house, and your AI app reads it. So use a new chat with no files and nothing else added.

  • In the house, everyone is an admin with demo / demo. Break things: it all comes back at the next reset. Don’t connect real devices.
