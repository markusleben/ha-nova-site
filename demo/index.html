A test Home Assistant house with no real devices. Look around before you connect your own.

Before you open the demo

Public demo: everyone shares one account. Other visitors can see what you enter until the next reset. Never enter real names, addresses, passwords, API keys, or tokens. Don’t connect real accounts or devices.

One shared house, one shared login, a fresh start every hour.

Talk to the demo house in Claude

Nothing to install. A free Claude account works. Add it on the web or in the Claude desktop app; then it works in the Claude phone app too.

Add to Claude

A free Claude plan can add one connector of its own. Already used it? Remove that one first in Claude: Settings → Connectors.

  1. Add it. Choose Add to Claude. Claude opens with the demo filled in. If it asks how to sign in, choose “Sign in now” and “Use Claude’s published identity”. Then choose Add.
  2. Log in. The demo house’s login opens (if not, choose Connect). It asks to let Claude in: that is the demo, not your home. Type demo and demo.
  3. Ask. Open a new chat and say: “In the demo house, turn off the kitchen lights.”

  • Unlocking a door asks you first. Here, Claude shows a short code, and you type it back. Claude sees the code too, so it is a light check. At home, a linked phone asks instead.

  • The house resets at the top of every hour, which takes a few minutes. Then the demo signs Claude out. In Claude, choose Connect next to the demo in Settings → Connectors, and log in with demo / demo.

  • Claude asks before each step at first. To ask less, open Settings → Connectors → HA NOVA demo. Set the read-only tools and “Control a device” to “Always allow”. Leave “Run a confirmed change” on “Needs approval”: the demo has no phone, so that question is the check before the door unlocks.

  • Other visitors can write text in the house, and Claude reads it. Use the demo in a new chat with no files and no other connectors on.

  • Done? Remove the demo in Claude: Settings → Connectors. That frees the slot for your own home.
