# ha-nova-site

Source for the HA NOVA landing page — a static one-pager deployed via GitHub Pages at [hanova.app](https://hanova.app/).

**Living documents:**

- [`CLAUDE.md`](CLAUDE.md) — working rules for AI-assisted development of this page
- [`PRODUCT.md`](PRODUCT.md) — product truth, audience, hard content rules
- [`DESIGN.md`](DESIGN.md) — the visual system ("The Legible Cosmos")

**Content rule:** the product repo [markusleben/ha-nova](https://github.com/markusleben/ha-nova) (README + docs) is always the source of truth — check it before every content change. Published features only, no version numbers, "App" (never "Add-on"), Cloud access always labeled Beta.

Brand assets are vendored in [`assets/`](assets/) from the released product state. The original build brief (`PROMPT.md`) served its purpose and lives on in git history.
